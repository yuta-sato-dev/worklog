タイトルを取得できないとき

Macでは、この画面の「許可を設定」を押して、表示されたシステム設定でWorklogを有効にしてください。開発版とインストール版は別のアプリとして扱われます。許可後にWorklogを再起動してください。

ブラウザは選択中のタブが公開するタイトルを記録します。チャットや書類の名前がタイトルに出ていない場合、その名前は取得できません。

ターミナルのプロジェクト名

Macのzshでは、次の設定を ~/.zshrc に追加して新しいターミナルを開くと、Gitリポジトリ名を記録できます。Gitの外では現在のフォルダ名を使います。

autoload -Uz add-zsh-hook
_worklog_title() {
  local root
  root=$(git rev-parse --show-toplevel 2>/dev/null) || root="$PWD"
  root="${root//[$'\e\a\n\r']/}"
  printf '\033]2;worklog:%s\007' "$root"
}
add-zsh-hook precmd _worklog_title

ターミナルやテーマがタイトルを上書きする場合は調整が必要です。

終了すると記録が止まります。
